## Usage

### In READMEs

```markdown
![Made by onoht](https://img.shields.io/badge/made%20by-onoht-black?style=flat)
```

### Logo

Use the ◯ character directly, or link to SVG:

```markdown
![onoht](https://raw.githubusercontent.com/onoht/branding/main/logos/onoht-circle-black.svg)
```

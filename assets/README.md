# Assets

Logo and brand assets for onoht.

## Logo Files

### SVG (Vector)

| File | Description | Use Case |
|------|-------------|----------|
| `logo-black.svg` | Black circle on transparent | Light backgrounds, print |
| `logo-white.svg` | White circle on transparent | Dark backgrounds |
| `logo-black-on-white.svg` | Black circle on white square | Profile images, downloads |
| `logo-white-on-black.svg` | White circle on black square | Dark mode avatars |
| `icon.svg` | 512x512 icon format | App icons, social media |
| `favicon.svg` | 32x32 favicon | Browser tabs |

### PNG (Raster)

| File | Size | Use Case |
|------|------|----------|
| `logo-512.png` | 512×512 | Standard size (white on black) |
| `logo-black.png` | 512×512 | Light backgrounds |
| `logo-white.png` | 512×512 | Dark backgrounds |
| `logo-black-on-white.png` | 512×512 | Profile images |
| `logo-white-on-black.png` | 512×512 | Dark avatars |
| `logo-256.png` | 256×256 | Medium size |
| `logo-128.png` | 128×128 | Small size |
| `logo-64.png` | 64×64 | Icons, thumbnails |
| `icon.png` | 512×512 | App icons |
| `favicon.png` | 32×32 | Browser tabs |

## Badge

| File | Description |
|------|-------------|
| `badge.svg` | "made by onoht" badge for READMEs |
| `banner.svg` | Wide banner format |

## Usage

```markdown
<!-- Badge in README -->
![Made by onoht](https://raw.githubusercontent.com/onoht/onoht/main/assets/badge.svg)

<!-- Logo -->
<img src="https://raw.githubusercontent.com/onoht/onoht/main/assets/logo-black.svg" width="100" alt="onoht">
```

## Design Notes

- The logo is the Unicode character ◯ (U+25EF LARGE CIRCLE)
- Pure black (#000000) and white (#ffffff) only
- No gradients, no colors, no effects
- Minimal, honest, code-like
